FAQ

代理常见问题

代理价最低能到多少？
取决于月采购量与结算方式，量越大单价越低。给出预估量后会直接报实价，不做「先交加盟费」这类操作。
支持 API 自动发货吗？
支持。常见形态是预充值余额 + 接口下单，接口返回委托交易哈希。具体字段与鉴权方式在对接阶段提供。
可以只做转售、不囤货吗？
可以。你按零售价或代理价采购，再向你的客户报价，中间差价即你的利润，无需囤能量。
异常订单怎么处理？
金额不符、网络错误等异常会进入人工队列，代理可批量提交交易哈希，由专人核对处理。
